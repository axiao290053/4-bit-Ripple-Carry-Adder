# 4-bit-Ripple-Carry-Adder
4-bit Ripple Carry Adder built and simulated in CircuitVerse. This simulator adds two 4-bit binary numbers similar to vertical addition in binary except using rules of binary arithmetic where a carry is need when the addition of 2 bits (adding from the least significant bit to the msot significant bit) produces a sum greater than 1 in binary.
